## Posicionamento

- A primeira carta vai em qualquer lugar.
- As seguintes precisam ficar **ortogonalmente adjacentes** a pelo menos uma carta do seu reino.
- O reino precisa terminar como uma grade **3×3**: nunca coloque uma quarta carta numa linha ou coluna.
- Como a grade se forma aos poucos, a linha/coluna de uma carta só fica definida quando as vizinhas chegam.

## Descontos

- Cartas de **Desconto** reduzem o custo das próximas compras (de Castelo, de Vilarejo ou de todas).
- Descontos se somam. Uma carta não custa menos que 0 e o excedente não volta como ouro.
- O desconto de uma carta não vale para a própria compra.

## Cartas viradas para baixo

- Não têm custo, efeito, tipo nem pontos (valem 0).
- Ao colocá-la, ganhe **6 de ouro e 2 chaves**.
- Não movem o mensageiro.

## Bolsas

- Cartas com **bolsa** guardam ouro no fim do jogo, até o máximo indicado no texto de pontos.
- Ouro fora de bolsas não vale pontos (mas serve para desempate).
